# UIN Architecture

Version 1.0

## Architecture Philosophy

UIN is an Intent-centered platform.

The architecture must protect the core product idea:

Intent comes first.

Profiles, friendships, matching, activities, reputation, notifications and AI exist only to help users create, discover, match, fulfill, reflect on and integrate Intent.

UIN must not evolve into a profile-first social network, content platform or follower economy.
