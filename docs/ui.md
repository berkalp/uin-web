# UI Philosophy

Version 1.0

---

# Philosophy

UIN is not designed to maximize screen time.

It is designed to maximize real life.

The interface should disappear.

Users should spend their energy fulfilling Intent, not navigating menus.

Every screen must answer one question:

"What do you want to do?"

Never:

"What do you want to watch?"

---

# Core Design Principles

Intent First

Clarity Over Decoration

Action Over Content

Calm Interface

Fast Interaction

Privacy First

Accessibility First

Mobile First

Consistency Always

# Layout Principles

One primary action per screen.

# Activity Screen

# Reflection Screen

Optional note.

Private by default.

---

# Notifications

Only meaningful notifications.

Examples

Match Found

Activity Tomorrow

Join Request

Invitation

Reflection Reminder

Trust Updated

Never

Random engagement

Daily streaks

Someone viewed you

Every empty state should encourage action.

Example

No Intent yet.

↓

Create your first Intent.

Not

There is nothing here.

---

# Search

Search focuses on

Intent

Activities

Categories

Places

Organizations

Not profile popularity.

---

# Cards

Cards are the primary UI element.

Types

Intent Card

Activity Card

Profile Summary

Portfolio Entry

Notification

Reflection

Cards should be simple.

---

# Buttons

Primary

Green

Secondary

Outlined

Danger

Red

Never more than one primary button per screen.

---

# Icons

Simple outline icons.

Consistent style.

Never decorative.

Icons support understanding.

Never replace text.

---

# Motion

Animations should communicate.

Never entertain.

Examples

Loading

Expansion

Confirmation

Navigation

Motion must be subtle.

---

# Loading States

Always informative.

Skeletons preferred.

Avoid unnecessary spinners.

---

# Error States

Errors should explain

What happened

Why

How to recover

Never display technical jargon.

---

# Success States

Celebrate quietly.

Example

Intent Published

Activity Completed

Portfolio Updated

Trust Increased

Avoid excessive celebration.

---

# Forms

Prefer

Selection

Autocomplete

Suggestions

Templates

Voice

Avoid typing whenever possible.

---

# AI Integration

AI appears as an assistant.

Never as the center of attention.

Examples

Suggest better title

Improve wording

Recommend location

Suggest visibility

Recommend participants

AI never interrupts users.

---

# Accessibility

WCAG compliance.

Keyboard navigation.

Screen reader support.

High contrast.

Large touch targets.

Readable font sizes.

Accessibility is mandatory.

---

# Mobile First

Never the opposite.

Planning

Portfolio

# Desktop

Power users

Large planning

---

# Dark Mode

Supported.

Readable.

Calm.

---

# Privacy Indicators

Visibility must always be obvious.

Examples

Friends

Close Friends

Private

Users should never wonder who can see their Intent.

---

# Trust Indicators

Displayed quietly.

Examples

Verified

Reliable

Organizer

Community Builder

Never displayed as popularity.

---

# Social Principles

No follower counts.

No likes.

No reels.

No endless feed.

No stories.

No viral mechanics.

No engagement bait.

The UI should encourage leaving the application to live the experience.

---

# Design Success Metrics

Users create Intent quickly.

Users discover meaningful Intent.

Users complete Activities.

Users return because life improved.

Not because scrolling became addictive.

---

# Final Principle

The best UIN interface is one that users forget exists.

The screen is only a bridge.

Real life is the destination.
