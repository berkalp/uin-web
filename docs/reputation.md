# Reputation System

Version 1.0

---

# Philosophy

Reputation in UIN is earned.

It is never purchased.

It is never gamified.

It is never based on popularity.

The Reputation System exists to answer one question:

"Can this person be trusted to fulfill Intent?"

Nothing else.

---

# Core Principle

Reputation measures behavior.

Not personality.

Not influence.

Not beauty.

Not wealth.

Not follower count.

Not profile popularity.

Only real-world reliability.

---
